# ForgeFit v2

Premium dark navy/coral fitness app starter. Includes responsive dashboard, weekly beginner workout plan, nutrition logging, progress check-ins, local backup/restore, and an in-app animated exercise guide modal.

## Publish on GitHub Pages
1. Extract this ZIP.
2. In your existing GitHub repository, replace the old app files with these files.
3. Keep `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`, and `README.md` in the repository root. Upload the `assets` folder too.
4. Commit changes to `main`. GitHub Pages will redeploy automatically.
5. Refresh the site. If it was already installed on iPhone, close and reopen it after deployment.

## Important
Exercise demonstrations in this version are animated illustrations with written instructions, not filmed MP4 videos. They play inside the app and do not send users to YouTube or show YouTube ads. Filmed demonstrations can be added later using properly licensed MP4 files. App data is stored locally in the browser; export backups regularly. Google Fonts need internet; the app shell is cached for offline use after first load.
